# Benchmark Source Status

**Reference source, not a turnkey public rerun.** No benchmark is started by CI or package checks.

For existing manuscript evidence, use [the claim-source index](../docs/provenance/CLAIM_SOURCE_INDEX.csv) and the batch/mode-specific frozen summaries. Files under `reference/` preserve the measured driver/helper with portability changes; their CLI does not supply missing private inputs or reapprove changed identities.

A future rerun requires authorized model/config/checkpoint/weight artifacts, reviewed local runner/spec identities and an uncontested compatible GPU. The historical helper/spec SHA relationship does not automatically survive path adaptation. See [execution scope](../REPRODUCIBILITY.md) and [limitations](../LIMITATIONS.md). Do not merge new partial measurements into frozen results or relabel the historical Mamba checkpoint as corrected seed 42.
